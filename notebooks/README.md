### Project layout

- `notebooks/`: original working English notebook files and shared images/data
- `notebooks/en/`: English-language catalog linking to the working originals
- `notebooks/ro/`: Romanian translations of the 11 notebooks
- `notebooks/hu/`: Hungarian translations of the 11 notebooks
- `qnn/`, `raspberry_pi/`: shared model/framework sources and Raspberry Pi support, not duplicated per language

**Compatibility:** the original English notebook locations, original model assets and Python inference algorithms have not been moved. The PYNQ translations adjust only the notebook data-directory lookup to check the parent folder; the Raspberry Pi translations retain identical Python code. User-facing messages generated by Python code can still appear in English, because execution logic and interfaces were preserved.

**Validation:** these translations passed a structural/code-difference review, **not execution on physical PYNQ or Raspberry Pi hardware**. Hardware and numerical validation are still required. Do not interpret translated copies as independently tested experiments.

### English-only restoration point
