Educational laboratories by Prof. dr. ing. habil. Stefan Oniga, using the original Xilinx QNN-MO technical framework.

| Language | Open | Status |
| --- | --- | --- |
| **English** | [English laboratories](en/README.md) | Available: all 11 notebooks |
| **Română** | [Laboratoare în limba română](ro/README.md) | Translation not yet available |
| **Magyar** | [Magyar nyelvű laboratóriumok](hu/README.md) | Translation not yet available |

**Important for PYNQ installations:** The working English notebook files remain directly in `notebooks/` to preserve their existing relative paths to images, models and test data and the current installation procedure. The `en/` folder provides a language-specific catalog linking to those original files rather than creating potentially divergent duplicates. Folders `ro/` and `hu/` are prepared for translated content. Nothing has been moved or modified in the executable notebooks.

All language versions will use the same original Xilinx QNN-MO framework, license and technical assets. Translations should change teaching text, not tested code.
