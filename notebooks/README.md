# QNN-MO-PYNQ — Choose your language

Educational laboratories by **Prof. dr. ing. habil. Stefan Oniga**, built on the original Xilinx QNN-MO framework.

| Language | Open | Status |
| --- | --- | --- |
| **English** | [English laboratories](en/README.md) | Complete — 11 working notebooks |
| **Română** | [Laboratoare în limba română](ro/README.md) | Translation in progress — labs 01–03 available |
| **Magyar** | [Magyar nyelvű laboratóriumok](hu/README.md) | Fordítás folyamatban — 01–03 elérhető |

**Compatibility:** the original English notebooks stay directly in `notebooks/` to preserve existing PYNQ installation paths, data and links. The `en/` folder is an index to these original files. Romanian and Hungarian translations have separate notebooks in their own directories, with shared data and original Xilinx code. Hardware validation of translated copies remains pending.

**Reversible change:** the repository state before the multilingual layout is preserved in the read-only-intended [English-only backup branch](https://github.com/onigas/QNN-MO-PYNQ/tree/backup/english-only-2026-11-05). Do not modify or delete that branch if you want to retain the rollback point.
